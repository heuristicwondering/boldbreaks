# boldbreaks
A BIDS App for finding changepoints in fMRI timeseries.

## Ways to use the app
There are three ways to run this app.
1. Use the official released singularity image (RECOMMENDED).
   + This can be found at: TK
2. Build the image from the container definition file.
   + The definition is `./container/boldbreaks`
3. Run the code without a container, locally. (LEAST RECOMMENDED)
   + The source is found under: `./src/boldbreaks/`

The image is hosted as a docker image. You can use this directly or convert to a singularity image.
